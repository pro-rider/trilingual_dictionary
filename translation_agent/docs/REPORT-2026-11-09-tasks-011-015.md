## TASK 013 — Guard-bypass verification

**VERIFIED by executed tests: 14 passed, 3 xfailed (bypasses recorded, not fixed).**

Guard logic, exactly: resolve with `os.path.realpath`, then refuse if the
lowercased filename is in `{dictionary.sqlite, translations.db}` **or** if the
lowercased resolved path contains `backend/data/build` or `assets/data`.
It is path-based — no inode, device, or content check.

| variant | expected | actual | evidence |
| --- | --- | --- | --- |
| absolute path | refuse | refused | `test_absolute_path_is_refused` |
| relative path | refuse | refused | `test_relative_path_is_refused` |
| `.` / `..` segments | refuse | refused | `test_dot_and_dotdot_segments_are_refused` |
| symlink to protected | refuse | refused | `test_symlink_to_protected_is_refused` (realpath resolves) |
| mixed `/` and `\` | refuse | refused | `test_mixed_separators_are_refused` |
| uppercase filename | refuse | refused | `test_uppercase_name_is_refused` |
| same name, unrelated dir | refuse | refused | `test_differently_named_parent_is_refused` |
| env override via `TRANSLATION_AGENT_LEDGER` | refuse | refused | `test_env_override_cannot_point_at_production` |
| `file:` URI form | refuse | refused | `test_file_uri_is_refused_even_without_markers` (by accident: `realpath` keeps the basename) |
| **`?mode=rw` suffix** | refuse | **ALLOWED** | xfail `test_bypass_uri_query_suffix` |
| **trailing space** | refuse | **ALLOWED** | xfail `test_bypass_trailing_space` |
| **hardlink under an innocent name** | refuse | **ALLOWED** | xfail `test_bypass_hardlink` |
| unrelated temp database | allow | allowed | `test_unrelated_database_is_allowed` |

Severity: the first two bypasses require the file to sit *outside*
`backend/data/build`; the real production files are inside it, so the marker
check catches them today — proven by `test_marker_check_masks_the_suffix_bypasses`.
The hardlink bypass is real in any directory and cannot be fixed by path logic.
Proposed fix (not applied): keep an explicit allow-list of protected inodes
(`os.stat().st_dev/st_ino`) captured at startup, or refuse whenever the guard
is handed anything containing `:`, `?`, or trailing whitespace.

Structural guards, also tested: `sqlite3.connect` appears exactly once in
`src/` (in the ledger); export with zero approved candidates returns a
